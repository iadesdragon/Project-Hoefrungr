# Project Höfrungr

Engineering repository for the Höfrungr VTOL UAV project.

## Scope

- AtomRC Dolphin VTOL proof of concept
- SkyPack intelligent battery system
- Custom Smart BMS
- iNAV integration
- Mechanical, electrical and firmware co-development
