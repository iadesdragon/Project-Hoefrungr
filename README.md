# Engineering Workspace

This Git repository contains the reusable Engineering Platform and the first reference project, Höfrungr.

## Structure

```text
engineering_platform/      Reusable standards, templates, workflows and knowledge base
projects/Hoefrungr/        First reference project using the platform
archive/                   Inactive legacy material, if needed later
```

## Principle

The Git repository is the Engineering Truth. Chat discussions are working material; accepted results are integrated through Engineering Change Packages (ECPs).

## Current baseline

- ECP: HOF-ECP-0001
- Platform baseline: ENG-PLT-v0.1
- Project baseline: HOF-v1.0-engineering-baseline
