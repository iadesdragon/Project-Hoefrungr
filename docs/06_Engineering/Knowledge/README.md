# Knowledge Base

Dieses Verzeichnis enthält projektübergreifende Erkenntnisse, Erfahrungen und offene Punkte, die während der Entwicklung von Höfrungr entstehen.

Ziel ist es, nicht nur das technische Ergebnis zu dokumentieren, sondern auch den Entwicklungsweg, die Zusammenarbeit mit KI und die daraus gewonnenen Erkenntnisse nachvollziehbar festzuhalten.
