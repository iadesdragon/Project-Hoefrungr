# Engineering Platform

The Engineering Platform contains reusable standards, templates, workflows and knowledge that can be used to initialize and operate hardware/software engineering projects.

Höfrungr is the first reference project used to validate and improve this platform.

## Platform intent

Each project improves not only the developed system, but also the development process itself. Findings from architecture, implementation, verification and AI-assisted engineering are evaluated and fed back into this platform.

## Separation

- `engineering_platform/` defines **how** we develop.
- `projects/<ProjectName>/` contains **what** we develop.
