# ENG-STD-001 Repository Standard

| Field | Value |
|---|---|
| Standard ID | ENG-STD-001 |
| Title | Repository Standard |
| Version | v0.1 |
| Status | Draft |

## Purpose

Define the reusable repository layout for engineering projects.

## Workspace structure

```text
engineering_platform/
projects/<ProjectName>/
archive/
```

The platform contains reusable process assets. Project repositories contain project-specific technical and management artifacts.

## Rule

The Git repository is the Engineering Truth. Accepted project knowledge must be represented in version-controlled files, not only in chat history.
