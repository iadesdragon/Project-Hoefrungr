# ENG-STD-002 Document Standard

| Field | Value |
|---|---|
| Standard ID | ENG-STD-002 |
| Title | Document Standard |
| Version | v0.1 |
| Status | Draft |

## Purpose

Define minimum expectations for engineering documents.

## Mandatory header fields

- Document ID
- Title
- Version
- Status
- Project or Platform scope
- Owner / responsible role

## Fundamental principle

Every document must have a clear purpose in the systems-engineering process. Documents are not created to demonstrate completeness, but to enable better technical decisions.
