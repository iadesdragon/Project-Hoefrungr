## Purpose

This Engineering Change Package establishes the first combined Git-based workspace for:

1. the reusable Engineering Platform, and
2. the Höfrungr reference project.

The package preserves already created project documents, consolidates the repository structure, separates reusable platform assets from project-specific artifacts, and introduces the ECP process as the formal change mechanism.

## Integration rule

The contents of `repository/` represent the proposed repository state after applying this ECP.
