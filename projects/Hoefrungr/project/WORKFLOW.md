# Workflow

Version: 0.1  
Status: Initial

## Grundprinzip

Der Chat dient als Entwicklungsraum. Git dient als verbindlicher Wissensspeicher.

## Standardablauf

1. Idee oder Fragestellung im Chat entwickeln
2. Technische oder prozessuale Bewertung durchführen
3. Entscheidung oder Zwischenergebnis formulieren
4. Ergebnis in passendes Dokument überführen
5. Änderung in Git committen
6. Offene Punkte dokumentieren

## Dokumentationsentscheidung

- Anforderungen → SRS
- Architektur → HDD
- Schnittstellen → Interface-Dokumente
- Grundsatzentscheidungen → ADR
- Vorläufige Ideen → Concepts
- Recherche → Research
- Erkenntnisse → Knowledge
- Arbeitsweise → Project Workspace
