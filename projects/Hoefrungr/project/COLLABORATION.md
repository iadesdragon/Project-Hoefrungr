# Collaboration Model

Version: 0.1  
Status: Initial

## Rollenverständnis

Der Systementwickler trifft fachliche und technische Entscheidungen.

Die KI unterstützt durch:

- Strukturierung
- Dokumentation
- Konsistenzprüfung
- Variantenanalyse
- Formulierung von Anforderungen
- Vorbereitung von Entscheidungen
- Erkennen offener Punkte

## Verantwortung

Die KI liefert Vorschläge, Entwürfe und Prüfungen. Die Verantwortung für technische Entscheidungen bleibt beim menschlichen Systementwickler.

## Arbeitsmodus

Die Zusammenarbeit erfolgt iterativ:

```text
Diskussion → Strukturierung → Dokumentation → Review → Git → Weiterentwicklung
```
