## LL-001 – Projekterkenntnisse müssen aktiv gesichert werden

Datum: 2026-07-03  
Bereich: Prozess / KI  
Status: Beobachtung

### Ausgangslage

Während der frühen Projektphase wurde erkannt, dass wertvolle Erkenntnisse im Chatverlauf verloren gehen können, wenn sie nicht aktiv in Git überführt werden.

### Erkenntnis

Der Chat ist ein Arbeitsraum, aber kein zuverlässiger Wissensspeicher.

### Konsequenz für das Projekt

Wichtige Erkenntnisse werden künftig in Knowledge-Dokumenten, ADRs oder projektbezogenen Protokollen abgelegt.

### Übertragbarkeit auf zukünftige Projekte

Für langfristige KI-gestützte Entwicklungsprojekte sollte von Beginn an ein versionierter Wissensspeicher eingerichtet werden.
